# Path-Aware Network Simulator

A **SimPy-based discrete-event simulator** for evaluating path selection strategies in path-aware networks.

## Features
- Axiomatic framework for testing different path selection algorithms  
- Models congestion and packet loss behavior realistically  
- Compare 7 algorithms across multiple topologies under varied traffic loads
